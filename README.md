# Sales Secretary legal page

English privacy policy, German Impressum and German privacy notice, published
at https://lisiq.github.io/sales-secretary-legal/ from
https://github.com/lisiq/sales-secretary-legal (main, repository root).

This folder is a maintained copy in the app repository. It is **not** a nested
git repository. Updating only salessecretary does not publish the legal site;
commit the same index.html and README.md to sales-secretary-legal as well.

The September 21, 2026 policy describes optional iCloud sync from version 1.6,
including existing records, photos, custom lists, currency, attention days,
offline copies and synced deletion. Earlier versions remain local-only.
It also describes MapKit suggestions, external maps, StoreKit, local reminders,
iCloud background notifications, exports, PDF reports and widget summaries.

The app continues to link Apple's standard EULA for Terms of Use. No separate
app account or custom account contract is introduced. Keep the policy and
App Store privacy answers aligned with actual data handling. The developer has
no access to CloudKit private user records; no analytics or tracking is added.

Bump the effective date in both languages whenever data handling changes.
